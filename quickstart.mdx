title: "Quickstart: Run the DBOO Event Manager in NetBeans"
sidebarTitle: "Quickstart"
description: "Clone the DBOO repository, configure the hardcoded db4o database path in Inicio.java, add the db4o JAR, and launch the application in NetBeans IDE."
---

This guide walks you through cloning the DBOO repository, opening both NetBeans projects, updating the hardcoded `.yap` database path for your local machine, adding the required db4o library, and launching the application for the first time. Follow each step in order — the application will not start without a valid database path configured in `Inicio.java`.

<Steps>
  <Step title="Clone the Repository">
    Clone the project from GitHub using the following command:

    ```bash
    git clone https://github.com/MauricioFajardo/orientado_objetos.git
    ```

    This creates the `orientado_objetos/` directory containing two NetBeans projects:
    - `Proyecto_final/` — the main event management application
    - `Trabajo_db4o/` — the standalone db4o demonstration module
  </Step>

  <Step title="Open in NetBeans">
    Open **NetBeans IDE 8.x or later** and import both projects as existing projects:

    1. Go to **File → Open Project** and navigate to the cloned `orientado_objetos/` root directory. Select `Proyecto_final` (it contains `build.xml` and the `nbproject/` folder) and click **Open Project**.
    2. Repeat **File → Open Project** and select the `Trabajo_db4o/` subdirectory to open that project as well.

    The `nbproject/project.xml` file identifies the main project name as `Proyecto_final` and registers `src/` as the sole source root:

    ```xml
    <name>Proyecto_final</name>
    <source-roots>
        <root id="src.dir"/>
    </source-roots>
    ```
  </Step>

  <Step title="Configure the Database Path">
    Before running the application, update the `.yap` file path to a location that exists on your machine. Open `src/proyecto_final/Inicio.java` and locate the static field `direccion` near the top of the class:

    ```java
    public static String direccion = "C:\\Users\\HP\\Documents\\GitHub\\orientado_objetos\\pro.yap";
    ```

    Replace the value with an absolute path to a directory that exists on your system — db4o will create the `.yap` file automatically on first run if it does not yet exist. For example:

    ```java
    // Windows
    public static String direccion = "C:\\Users\\YourName\\Documents\\dboo\\pro.yap";

    // macOS / Linux
    public static String direccion = "/home/yourname/dboo/pro.yap";
    ```

    <Warning>
      The directory portion of the path (e.g. `C:\Users\YourName\Documents\dboo\`) **must already exist**. db4o creates the `.yap` file but will not create missing parent directories.
    </Warning>
  </Step>

  <Step title="Add the db4o Library and Run">
    The project requires the db4o JAR at compile time and runtime. Add it in NetBeans:

    1. Right-click the `Proyecto_final` project in the Projects panel and choose **Properties**.
    2. Select **Libraries** in the left panel, then click **Add JAR/Folder**.
    3. Browse to your db4o JAR (e.g. `db4o-8.x-all-java5.jar`) and click **Open**, then **OK**.

    Once the library is on the classpath, right-click `Proyecto_final` and choose **Run** (or press F6). NetBeans will compile and launch the `Proyecto_final` main class, which is the application entry point:

    ```java
    public static void main(String[] args) {
        Inicio log = new Inicio();
        log.setVisible(true);
        log.setLocationRelativeTo(null);
    }
    ```

    This instantiates the `Inicio` JFrame, centres it on screen, and makes it visible.
  </Step>
</Steps>

<Note>
  The application opens to the `Inicio` (Welcome) screen, where you can log in as Administrator, Organizer, or register as Public/Merchant. Use the **INICIO COMO:** menu bar item to select Administrator or Organizer login, or click **CREAR CUENTA** to self-register as a public attendee. To request a merchant booth, use the **SOLICITAR PUESTO → Crear Cuenta** menu option.
</Note>
