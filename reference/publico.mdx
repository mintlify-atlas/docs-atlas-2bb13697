`Publico` models a member of the general public who registers to attend an event. It extends `Persona` for all personal identification data and adds ten additional fields that capture the attendee's ticket type, registration status, preferences, payment amount, and foreign keys linking to related entities such as uploaded images, surveys, event ratings, and comments. `Publico` is the most relationship-rich subclass in the `Persona` hierarchy.

## Constructors

### No-argument constructor

```java
public Publico()
```

Delegates to `super()`. All fields are `null` / `0.0`. Used by db4o during object reconstruction.

### Full constructor

```java
public Publico(
    String codigo_publico,
    String Tipo_Entrada,
    String Estado_reguistro,
    String Preferencias_p,
    double Pago_p,
    String codigo_sube_ima,
    String codigo_encuesta,
    String califica_eve,
    String codigo_comen,
    String cedula_persona,
    String cedula,
    String nombre,
    String apellido,
    String telefono,
    String correo,
    String direccion,
    String celular,
    Date   fecchaNaci,
    String genero
)
```

The first ten parameters populate `Publico`-specific fields; the remaining nine are forwarded to `super(cedula, nombre, ...)`.

<ParamField path="codigo_publico" type="String" required>
  Primary key. Unique identifier for this attendee registration record.
</ParamField>

<ParamField path="Tipo_Entrada" type="String" required>
  Type of ticket purchased (e.g., general admission, VIP, press).
</ParamField>

<ParamField path="Estado_reguistro" type="String" required>
  Registration status of the attendee (e.g., confirmed, pending, cancelled). Note: `reguistro` is preserved from source.
</ParamField>

<ParamField path="Preferencias_p" type="String" required>
  Attendee's stated preferences or interests relevant to event activities.
</ParamField>

<ParamField path="Pago_p" type="double" required>
  Amount paid by the attendee for registration or ticket purchase. Validated by `Validaciones.validarDouble()`.
</ParamField>

<ParamField path="codigo_sube_ima" type="String" required>
  Foreign key → image upload entity. Links the attendee to any images they have uploaded (e.g., profile photo).
</ParamField>

<ParamField path="codigo_encuesta" type="String" required>
  Foreign key → survey (Encuesta) entity. Links the attendee to a post-event survey record.
</ParamField>

<ParamField path="califica_eve" type="String" required>
  Foreign key → event rating (califica evento) entity. Links the attendee to their event rating record.
</ParamField>

<ParamField path="codigo_comen" type="String" required>
  Foreign key → comment (Comentario) entity. Links the attendee to their comment record about the event.
</ParamField>

<ParamField path="cedula_persona" type="String" required>
  Foreign key → `Persona.cedula`. Links this attendee registration to the person's core identity record.
</ParamField>

<ParamField path="cedula" type="String" required>
  Inherited: national 10-digit ID. Passed to `Persona` constructor.
</ParamField>

<ParamField path="nombre" type="String" required>
  Inherited: first name. Passed to `Persona` constructor.
</ParamField>

<ParamField path="apellido" type="String" required>
  Inherited: last name. Passed to `Persona` constructor.
</ParamField>

<ParamField path="telefono" type="String" required>
  Inherited: landline phone. Passed to `Persona` constructor.
</ParamField>

<ParamField path="correo" type="String" required>
  Inherited: email address. Passed to `Persona` constructor.
</ParamField>

<ParamField path="direccion" type="String" required>
  Inherited: address. Passed to `Persona` constructor.
</ParamField>

<ParamField path="celular" type="String" required>
  Inherited: mobile phone. Passed to `Persona` constructor.
</ParamField>

<ParamField path="fecchaNaci" type="java.util.Date" required>
  Inherited: date of birth. Passed to `Persona` constructor.
</ParamField>

<ParamField path="genero" type="String" required>
  Inherited: gender (`"H"` or `"M"`). Passed to `Persona` constructor.
</ParamField>
