DBOO is a full-featured event management system built in Java using the **db4o** object-oriented database engine. All application data — organizers, events, sponsors, merchants, staff, and attendees — is persisted directly as Java objects into a `.yap` file, with no SQL or relational schema required. The application provides a multi-role Swing GUI for administrators, organizers, and public users.
